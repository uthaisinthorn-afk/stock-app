วันที่สินค้าประเภทจำนวนคงเหลือหมายเหตุ
ยังไม่มีรายการเคลื่อนไหว
ยังไม่มีคำสั่งซื้อจากหน้าร้าน
คำสั่งซื้อจากหน้าร้านลูกค้า (shop.html) จะเข้ามาที่นี่แบบเรียลไทม์ กด "ยืนยัน/จัดส่ง/สำเร็จ" เพื่ออัปเดตสถานะให้ลูกค้าเห็น หรือ "ยกเลิก" เพื่อคืนสต็อกอัตโนมัติ
ทดลองใช้งาน: โหลดสินค้าเบ็ดเตล็ดตัวอย่าง 200 รายการเข้าระบบ (คละหมวด ทำความสะอาด/เครื่องเขียน/ไฟฟ้า/ประปา/ความปลอดภัย/อะไหล่ช่าง/HVAC/จัดเก็บ) เพื่อลองฟีเจอร์ต่างๆ ก่อนใช้ข้อมูลจริง
ข้อมูลตอนนี้ซิงค์ผ่าน Firebase (โปรเจกต์ stb-pm-system) — เปิดหน้านี้จากเครื่อง/มือถือคนละเครื่องจะเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ เก็บใน Firestore collection stock_products และ stock_tx คู่กับ eaf_pm_logs ที่มีอยู่แล้ว
เรื่อง LINE: LINE Notify ปิดบริการไปแล้ว เว็บนี้จึงไม่เรียก LINE โดยตรง (ติด CORS ด้วย) แนะนำตั้ง webhook ที่ n8n/Apps Script เป็นตัวกลางรับ POST จากหน้านี้ แล้วยิงต่อเข้า LINE Official Account (Messaging API) เว็บนี้จะส่ง JSON {sku,name,qty,min} ทุกครั้งที่สต็อกต่ำกว่าขั้นต่ำ
การตั้งค่านี้ (เกณฑ์ขั้นต่ำ/webhook) เก็บเฉพาะในเครื่องนี้เท่านั้น ไม่ซิงค์ข้ามอุปกรณ์
